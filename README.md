Hey there! Thanks for viewing my repo if you're here.

to actually use these if you don't know or have it already, you'll want to install Skript & Skbee.
Skbee isn't fully required for EVERYTHING, but I do 100% reccomend installing it because it just makes everything work. ya feel me? lol

Skript can be found here:
https://modrinth.com/plugin/skript
(make sure to download the EXACT version of your server, skript is picky af)

Skbee can be found here:
https://modrinth.com/plugin/skbee
(again, make sure to pick the EXACT version that matches your server. if it comes out red in /pl then search up which version of skript works with skbee,
I've had an issue like that in the past and it's annoying AF to get rid of)
